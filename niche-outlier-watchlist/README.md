# Niche Outlier Watchlist

A Creators Toolbox agent skill that builds a short watchlist of creators whose recent posts beat their own usual results. It is for research, not for copying posts.

## Install

```bash
npx skills add steven-van-opus/creators-toolbox-skills --skill niche-outlier-watchlist
```

Then ask your agent: "Use the niche-outlier-watchlist skill to find AI video-editing creators worth studying this month."

## Example

See [examples/ai-video-editing](./examples/ai-video-editing) for a worked watchlist template. The account rows are labelled as samples.
