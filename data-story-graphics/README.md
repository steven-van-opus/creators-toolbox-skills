# Data Story Graphics

A Creators Toolbox agent skill that turns a public dataset into one feed-ready graphic. It starts from a question worth answering, then builds a sourced table and a spec.

## Install

```bash
npx skills add steven-van-opus/creators-toolbox-skills --skill data-story-graphics
```

Then ask your agent: "Use the data-story-graphics skill to compare public starting prices of AI video editors listed on Creators Toolbox."

## Example

See [examples/ai-editor-prices](./examples/ai-editor-prices) for a worked spec. Prices in that folder are marked as samples and must be rechecked on the live product pages before anyone publishes the graphic.
