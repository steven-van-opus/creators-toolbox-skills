# Grok Bot Video Studio

A Creators Toolbox agent skill that plans a small, realistic Grok Bot week for a video creator: a few routines, a few skills, and a path from saved ideas to a published video.

## Install

```bash
npx skills add steven-van-opus/creators-toolbox-skills --skill grok-bot-video-studio
```

Then ask your agent: "Use the grok-bot-video-studio skill to plan my week. I make tool explainers, I bookmark hooks on X, and I edit in Tella."

## Example

See [examples/mira-tool-explainers](./examples/mira-tool-explainers) for a worked week for a fictional creator who makes short tool explainers and reads Creators Toolbox.
