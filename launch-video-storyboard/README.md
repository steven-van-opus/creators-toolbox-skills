# Launch Video Storyboard

Turn a product update into a timed plan that can be captured and edited by a small team. Bring your target platform and duration, the available shots, and the action the clip should demonstrate.

```bash
npx skills add steven-van-opus/creators-toolbox-skills --skill launch-video-storyboard
```

Try “Use launch-video-storyboard. Plan an 18-second product demo from these captures. Write the on-screen copy, list the shots I still need, and make the sequence understandable with the sound off.”

[Pinboard Hour shared boards](examples/shared-boards-storyboard.md) shows a scene-by-scene handoff for a fictional product update.

See the [Creators Toolbox guide](https://creatorstoolbox.com/@steven/post/g_agentic-social-post-design-skills) for the full workflow.
