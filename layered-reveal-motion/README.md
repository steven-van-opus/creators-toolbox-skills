# Layered Reveal Motion

Help an agent show how a product fits together with composed assembled and exploded views. Start with verified parts and make the separation explain one relationship.

```bash
npx skills add steven-van-opus/creators-toolbox-skills --skill layered-reveal-motion
```

Open the [trail lantern demo](./examples/trail-lantern.html) in a browser and toggle its layers. The demo uses CSS transforms, a native button, and an instant reduced-motion state. The [Creators Toolbox guide](https://creatorstoolbox.com/@steven/post/g_layered-reveal-motion-skill) walks through the scene and how to install the skill.

Inspired by [Anatomy Reveal by Ann Nguyen](https://github.com/annnguyentt/anatomy-reveal-skill). The instruction file and trail lantern example are original and [MIT-licensed](../LICENSE).
