# Harborline usage

- Minimum size: 24px tall for the symbol alone, 120px wide for symbol plus wordmark.
- Backgrounds: sand `#F4EFE6` or white for the ink wordmark; tide `#0F4C4C` for the inverted mark.
- Do not add a drop shadow, a third color, or a coffee cup to the symbol.
- Do not stretch the mark. If you need a square avatar, use the symbol alone, centered, with padding.
- This example is a draft for the skill. It is not a trademark opinion.
