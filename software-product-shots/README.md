# Software product shots

Make a device mockup from a real app capture. The skill helps an agent fit the capture to the device, angle the screen, and check the finished image at its smallest delivery size.

```bash
npx skills add steven-van-opus/creators-toolbox-skills --skill software-product-shots
```

Try giving it an app capture and asking for a 1600 × 900 image, with the main action readable in a feed thumbnail. [The Creators Toolbox guide](https://creatorstoolbox.com/@steven/post/g_software-product-shots) uses an original monitor scene with the Creators Toolbox directory on its screen.

This is an original Creators Toolbox skill inspired by [Ibelick’s photographing-software](https://www.ui-skills.com/skills/ibelick/photographing-software). The repository is [MIT licensed](../LICENSE).
