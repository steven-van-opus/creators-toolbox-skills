# Social Post Design Brief

Turn a product update into a card or carousel brief a designer can build from. Bring the release notes, the intended audience and destination, and any screenshots or brand assets.

```bash
npx skills add steven-van-opus/creators-toolbox-skills --skill social-post-design-brief
```

Try “Use social-post-design-brief. Use these release notes and captures to brief a feed card and a short carousel. Include final on-image copy and the crop for each frame.”

[Pinboard Hour shared boards](examples/shared-boards-brief.md) shows a brief for one fictional launch in both formats.

See the [Creators Toolbox guide](https://creatorstoolbox.com/@steven/post/g_agentic-social-post-design-skills) for the full workflow.
