# Pinboard Hour shared boards

Pinboard Hour is a fictional tool for collecting project links. This example assumes a feature release that lets solo designers share the contents of a board through a single URL. The reader should understand what the recipient will see. The action is to open the feature page.

Use the dark evergreen wordmark, cream paper background, and ochre accent from the fictional brand kit. Use demo data throughout. The project-board illustration is a layout reference. The actual carousel should use product captures before it ships.

## Feed card

Canvas at 1080 × 1350. Put the brand in the top left and set “Share the whole project board.” in two or three lines below it. Give the lower half to one screenshot of the shared view with “Studio handoff” and the three link names visible. Crop away project navigation. Keep release timing and the action link in the post caption.

Image description. Pinboard Hour's shared Studio handoff board shows three links grouped on one page.
