# Three.js Endless Parallax Ride

Use a reusable set of roadside tiles and world-space landmarks to give a looping route a sense of distance.

```bash
npx skills add steven-van-opus/creators-toolbox-skills --skill threejs-endless-parallax-ride
```

Serve the cloned repository with `python3 -m http.server --bind 127.0.0.1 8000` and open [the Salt Flat Crossing example](examples/salt-flat-crossing.html) from this folder. It loads a pinned Three.js module over HTTPS and uses WebGL 2. Pause or reset the skimmer ride and compare the movement of roadside markers and hills.

Read the [Creators Toolbox guide](https://creatorstoolbox.com/@steven/post/g_endless-3d-scroll-ride-with-threejs) for a workflow that connects the three techniques.

Inspired by [Cloud Pass by Meng To and ThreeUI](https://threeui.com/cloud-pass) and Meng To's [reference skill](https://github.com/MengTo/Skills/tree/main/agent-skills/3d/endless-riding-parallax). The instructions and example here are original and [MIT-licensed](../LICENSE).
