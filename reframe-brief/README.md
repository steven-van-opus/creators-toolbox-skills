# Reframe Brief

An original Creators Toolbox skill for turning “I know what I want, but I cannot name it” into a small, buildable brief. It offers concrete interpretations, keeps assumptions visible and ends with observable acceptance criteria and a handoff prompt.

## Install

```bash
npx skills add steven-van-opus/creators-toolbox-skills --skill reframe-brief
```

Or copy this folder into your agent's skills directory.

Ask: “Use reframe-brief to clarify this request before building: our class booking page needs to feel more like a timetable and less like a long list.”

See the original [booking example](examples/booking-request.md) and [saved-links example](examples/saved-links.md). The skill drafts a brief; it does not begin implementation or publish anything.
