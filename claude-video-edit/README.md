# Claude Video Edit

A Creators Toolbox agent skill for a small, beginner-friendly edit: one clip, one style reference, a beat list, then plain-language notes. It works with whatever AI editor the user already has.

## Install

```bash
npx skills add steven-van-opus/creators-toolbox-skills --skill claude-video-edit
```

Then ask your agent: "Use the claude-video-edit skill to plan an edit of my talking-head clip about a new tool listing, using this reference link."

## Example

See [examples/listed-this-week](./examples/listed-this-week) for a worked plan: a short talking-head about a tool that just listed on Creators Toolbox.
