# Weekly Creator News Show

A Creators Toolbox agent skill that plans a short weekly show from public posts and official sources: a rundown, a script, show notes, and a publish checklist.

## Install

```bash
npx skills add steven-van-opus/creators-toolbox-skills --skill weekly-creator-news-show
```

Then ask your agent: "Use the weekly-creator-news-show skill to plan this week's episode from these Scout links."

## Example

See [examples/toolbox-week](./examples/toolbox-week) for a worked rundown of a fictional weekly show that uses Creators Toolbox Scout posts as the research pile.
