# Toolbox Week, sample rundown

A fictional episode of a short show that covers creator tools. Stories would be replaced with live Scout posts and official pages in a real week.

1. A new agent skill or tool listing that actually shipped, with the official page as the source.
2. One practical change in a tool people already use (a price, a plan, or a feature that is live).
3. One shorter mention, only if there is a official source.

Open: what this week is about, in one sentence. Close: where to read the Scout posts. No "what we covered" recap.

Dropped: teasers, rumor posts, and anything without a official link.
