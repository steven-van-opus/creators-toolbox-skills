# Launch Greeting Card

A Creators Toolbox agent skill that plans a simple interactive card from a picture and a short message. It is aimed at product listings, thank-yous, and small congratulations, not at copying a 3D card engine.

## Install

```bash
npx skills add steven-van-opus/creators-toolbox-skills --skill launch-greeting-card
```

Then ask your agent: "Use the launch-greeting-card skill to make a card that says we listed Lampshade on Creators Toolbox."

## Example

See [examples/lampshade-listed](./examples/lampshade-listed) for a worked card spec congratulating a fictional tool named Lampshade on being listed.
