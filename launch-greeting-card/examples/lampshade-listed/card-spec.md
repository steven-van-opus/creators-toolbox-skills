# Lampshade listed: card spec

A sample for the launch-greeting-card skill. Lampshade is a fictional product.

## Front

The Lampshade screenshot sits in the center of a warm paper card, with a thin amber rule at the bottom and the word "Listed" in small caps. No other type on the front.

Motion: the card tilts a few degrees toward the pointer. A soft highlight slides across the screenshot. Nothing flashes, and the screenshot stays fully visible.

## Inside

A short handwritten-style note:

"Lampshade is live on Creators Toolbox. Thanks for sending it in."

Under it, a plain line: "The Creators Toolbox team"

## Back

The Creators Toolbox wordmark, small, and the listing URL written out in text so it still works if someone prints a screenshot.

## Alt text

"A greeting card with a screenshot of Lampshade on the front. It opens to a thank-you for listing the tool on Creators Toolbox."

## Build note

This example is a spec, not a shipped HTML file. When you build it, keep the three faces in one file and make sure the message is in the HTML as real text, not only in an image.
