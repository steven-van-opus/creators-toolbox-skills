# Pixel Art Character Builder

Build one original pixel-art character you can turn, animate, and take into a game or 3D project. The skill helps an agent keep the same baselines, joints, and features across the whole sheet.

```bash
npx skills add steven-van-opus/creators-toolbox-skills --skill pixel-art-character-builder
```

Open [Parcel the mailbox](./examples/parcel.html) locally in a browser. Turn it with the angle slider and compare the idle, flag wave, and hop poses. Try asking your agent to make a new mascot from one sentence and review four angles before producing action frames. The [Creators Toolbox guide](https://creatorstoolbox.com/@steven/post/g_pixel-art-characters-with-ai) includes an example brief and a 3D handoff.
