# Stick Explainer

A Creators Toolbox agent skill that storyboards a small stick-figure scene for a landing page. Each scene shows one product action, then settles back to an idle pose.

## Install

```bash
npx skills add steven-van-opus/creators-toolbox-skills --skill stick-explainer
```

Then ask your agent: "Use the stick-explainer skill to show someone pinning a Scout post onto a feed."

## Example

See [examples/pin-scout-post](./examples/pin-scout-post) for a worked storyboard: a figure pins a Scout post to a feed board.
